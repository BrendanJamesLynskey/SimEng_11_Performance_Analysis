# Simulation Engineering Toolkit 11 — Performance Analysis of Simulators and Systems

Measuring before optimising, on the simulators in this series: the USE method and the profile-first loop, Linux perf and what to do when it is locked down, sampling profilers and interactive flame graphs from py-spy, instruction counts with cachegrind (Rust against Python), a hot spot found in the metrics code and fixed with identical answers, benchmark distributions, and regression gates designed from measured noise.

Topics: USE method, py-spy, Flame graphs, cachegrind, Benchmark statistics, Regression gates.
